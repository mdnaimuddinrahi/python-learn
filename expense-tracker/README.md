# 💰 Expense Tracker

> A simple command-line Expense Tracker built with Python.

## 📖 Story

This is my **first Python project** after learning the fundamentals of the language. Instead of stopping at syntax and small exercises, I wanted to build a real application that solves a practical problem.

The goal of this project was to practice writing clean, modular Python code while implementing a complete CRUD (Create, Read, Update, Delete) application using only Python's built-in features.

---

## ✨ Features

* ➕ Add a new expense
* 📋 View all expenses
* 🔍 View expense details by ID
* ✏️ Update an existing expense
* 🗑️ Delete an expense
* 💰 Calculate total expenses
* ⚠️ Handle invalid numeric input

---

## ▶️ How to Run

Clone the repository:

```bash

```

Go to the project folder:

```bash
cd expense-tracker
```

Run the application:

```bash
python expense_tracker.py
```
