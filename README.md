# Python Mini Projects

A collection of beginner-friendly Python console applications built while learning and strengthening core Python programming skills.

These projects focus on building practical applications with plain Python, without relying on heavy frameworks or external databases.

## Projects

### 📊 Expense Tracker
A simple console application for recording, viewing, updating, and managing personal expenses.

**Concepts practiced:**
- Lists and dictionaries
- Functions
- Input validation
- File-based data storage
- Basic CRUD operations

### ✅ To-Do List
A console-based task management application for creating and managing daily tasks.

**Concepts practiced:**
- Lists and dictionaries
- Functions
- Loops
- Date handling
- Task priorities and statuses
- Input validation

### 🎓 Student Grade Manager
A student management application for storing student information, marks, grades, reports, rankings, and class statistics.

**Concepts practiced:**
- Nested dictionaries and lists
- List comprehensions
- Sorting
- Functions
- Calculations and aggregation
- Report generation

### 📞 Contact Book
A console application for managing contacts, including creating, searching, updating, and deleting contact information.

**Concepts practiced:**
- Dictionaries
- Lists
- Functions
- Searching and filtering
- CRUD operations
- Input validation

### 🩺 Doctor Appointment Booking
A practical console-based Doctor Appointment Booking Management System built with plain Python and JSON files.

The system manages doctors, patients, doctor schedules, and appointments while applying real-world appointment rules such as schedule-based time slots, appointment conflicts, status management, cancellation, and record history.

**Main features:**
- Doctor management
- Patient management
- Doctor schedule management
- Dynamic appointment slot generation
- Appointment creation and validation
- Appointment viewing and filtering
- Appointment updating
- Appointment status management
- Appointment cancellation
- JSON-based data storage
- Created and updated timestamps
- Business-rule validation for appointment conflicts

**Concepts practiced:**
- Functions
- Lists and dictionaries
- Nested data structures
- File handling
- JSON
- Date and time handling
- Input validation
- Searching and filtering
- CRUD operations
- Business logic
- Modular project structure

**Repository:** [Doctor Appointment Booking](https://github.com/mdnaimuddinrahi/python-learn/tree/main/doctor-appointment-booking)

## Purpose

These projects were built as practical exercises to strengthen Python fundamentals through progressively more realistic applications.

The goal was not only to learn Python syntax, but also to practice designing functions, organizing application logic, validating user input, working with files, and implementing real-world rules.
