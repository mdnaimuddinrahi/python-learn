# 📝 To-Do List CLI

A simple and interactive **Command-Line To-Do List application** built with **Python**.

This project is part of my Python learning journey after completing the core language fundamentals. Instead of building another tutorial project, I wanted to create something that solves a real-world problem while practicing clean code, modular programming, input validation, and CRUD operations.

The application allows users to manage daily tasks directly from the terminal by creating, viewing, updating, deleting, filtering, changing task status, and exporting tasks as JSON.

---

# ✨ Features

## 📌 Task Management

- ✅ Add a new task
- ✅ View a task by ID
- ✅ View all tasks
- ✅ Update task information
- ✅ Delete a task
- ✅ Change task status

---

## 🔍 Search & Filter

- ✅ Search tasks by title
- ✅ Filter tasks by priority
- ✅ Filter tasks by status

---

## ✔ Validation

- ✅ Input validation
- ✅ Confirmation before deleting
- ✅ Due date validation
- ✅ Prevent past dates
- ✅ Automatic task ID generation

---

## 📤 Export

- ✅ Export all tasks to a JSON file

---

## 📋 Task Information

Each task contains:

- 🆔 ID
- 📝 Title
- 📄 Description
- ⚡ Priority
- 📅 Due Date
- 📌 Status
- 🕒 Created Date

# ▶️ Getting Started

Clone the repository

```bash

```

Go to the project directory

```bash
cd todo-list
```

Run the application

```bash
python main.py
```
