# To-Do List CLI

A simple command-line To-Do List application built with Python. This project is part of my Python learning journey and focuses on practicing core Python concepts by solving a real-world problem.

## Features

### ✅ Completed

- Add a new task
- View task by ID
- View all tasks
- Search tasks by title
- Filter tasks by priority
- Filter tasks by status
- Auto-generated task ID
- Input validation
- Due date validation (YYYY-MM-DD)
- Priority selection
- Default task status
- Display task details
- Display tasks in a formatted table

### 🚧 Planned

- Update a task
- Delete a task
- Mark a task as completed
- Save tasks to JSON
- Task statistics

## Technologies

- Python 3
- Command Line Interface (CLI)
